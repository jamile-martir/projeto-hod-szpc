# 🐉 House of the Dragon

Um projeto Front-end desenvolvido durante um curso de programação, com o objetivo de apresentar alguns dos dragões do universo de **House of the Dragon** por meio de uma página interativa.

## Sobre o projeto

O site apresenta um carrossel com imagens e informações sobre sete dragões. Cada seleção permite visualizar a imagem, o nome e uma breve descrição do personagem.

O projeto foi desenvolvido como parte do meu processo de aprendizado em desenvolvimento Web, colocando em prática conceitos fundamentais de HTML, CSS e JavaScript.


## Funcionalidades

- Carrossel interativo de dragões.
- Exibição de imagens e descrições.
- Navegação entre os dragões por botões.
- Animações na transição das imagens.
- Layout responsivo para diferentes tamanhos de tela.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em seu navegador.
4. Explore o carrossel e conheça os dragões!
